# Hero Media

Ganti file `hero-car.mp4` dan `hero-poster.jpg` di folder ini untuk konten final.

## Spesifikasi rekomendasi

- **Video** (`hero-car.mp4`): 6–10 detik, 1920x1080, MP4 H.264, < 5 MB, tanpa audio.
- **Poster** (`hero-poster.jpg`): 1920x1080, JPEG, < 300 KB.

## Catatan

- Poster WAJIB ada: dipakai sebagai fallback saat video gagal dimuat,
  saat perangkat mobile (< 768px), dan saat `prefers-reduced-motion` aktif.
- Video hanya di-autoplay di desktop dengan kondisi motion normal.
